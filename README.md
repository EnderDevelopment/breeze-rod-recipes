# Minecraft Plugin: Breeze Rod Recipes

Breeze Rod Recipes is a Minecraft plugin for Paper servers that adds a shaped crafting recipe for Breeze Rods using Lapis Lazuli. Place nine Lapis Lazuli in the crafting grid to craft four Breeze Rods.

## Install

1. Download or build the plugin JAR.
2. Stop your Paper Minecraft server.
3. Copy the plugin JAR into the server's `plugins` folder.
4. Start the server.
5. Confirm that BreezeRodCrafting loads successfully in the server console.

To build the plugin from source:

1. Install Java Development Kit 21 and Maven.
2. Open a terminal in the project directory.
3. Run `mvn package`.
4. Copy the generated `target/plugin.jar` file to the server's `plugins` folder.
5. Restart the server.

## Use

1. Open a crafting table.
2. Fill all nine crafting slots with Lapis Lazuli.
3. Take the four Breeze Rods from the result slot.

The recipe uses nine Lapis Lazuli for each four Breeze Rods and is registered automatically when the plugin enables.
